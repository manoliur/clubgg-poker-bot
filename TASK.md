# ТЗ: доработка автономного покерного бота ClubGG

## Контекст
Бот играет в покер No-Limit Hold'em (кэш, клуб ClubGG) на телефоне Android (Redmi Note 13) через USB-отладку (adb). Телефон подключён к Windows-компьютеру, скриншоты снимаются через `adb exec-out screencap -p`, тапы через `adb shell input tap`.

Текущая архитектура:
- **Комп (Windows)**: adb-скрипты (shot.py, tap.py, auto_bot.py, card_reader.py)
- **Сервер (этот VPS)**: Claude Code (подписка Pro) используется как "мозг" — смотрит скриншот и решает ход

## ЦЕЛЬ: полностью автономный бот БЕЗ участия ИИ в реальном времени
Пользователь хочет, чтобы программа на Python сама:
1. Определяла очерёдность ставок (кто первый: от кнопки D — дилер; SB ходит первым на префлопе, BB первым на постфлопе)
2. Определяла свою руку (карманные карты) — распознавание карт по скриншоту
3. Определяла стол (доску — общие карты)
4. Определяла количество игроков
5. Оценивала силу руки (пары, стриты, флеши и т.д.)
6. Принимала решения по стратегии (чек/колл/фолд/рейз) без ИИ — по таблицам/правилам
7. Всё через adb-подключение к телефону

## Текущее состояние кода (в репозитории)

### Уже работает:
- `shot.py` — скриншот телефона через adb (важно: на Windows через git-bash бинарный вывод портится — снимать только через python subprocess!)
- `tap.py` — тап по координатам
- `card_reader.py` — РАСПОЗНАВАНИЕ КАРТ (НЕДОДЕЛАНО):
  - `build_templates.py` собирает эталоны рангов/мастей из скриншотов (templates/rank_X.png, templates/suit_X.png), нормализует к 50x66
  - `find_board_cards()` — cv2-детекция карт доски (белые прямоугольники 90-160x130-210)
  - `my_card_boxes()` — мои карты в нижней зоне (слипшийся контур делится на 2)
  - `recognize_corner()` — сравнение угла с эталонами через нормализованную корреляцию (numpy)
  - **ПРОБЛЕМА: мои карты всегда возвращают '??' — распознавание угла не работает (score < 0.3), хотя доска распознаётся. Надо отладить: почему угол моих карт не совпадает с эталонами (масштаб? позиция? split ранг/масть?)**
  - Не хватает эталона 'T' (10) — двузначный ранг
  - Масть корректируется по цвету (suit_color: красная/чёрная) — но h/d и c/s не различаются между собой

### НЕДОДЕЛАНО (главная работа):
1. **`hand_evaluator.py`** — оценка силы руки (7 карт → лучшая комбинация): нужно написать классический эвалюатор (high card, pair, two pair, trips, straight, flush, full house, quads, straight flush). Сравнение рук по рангам.
2. **Очерёдность ходов** — определение кто первый: кнопка D (золотой маркер) у игрока = дилер/SB. Позиции игроков на столе. Правила: префлоп первым SB (дилер), постфлоп первым BB.
3. **Определение количества игроков** — аватары/панели игроков на столе (кроме меня и внизу).
4. **Стратегия** (`strategy.py`) — табличная: префлоп-руки по позиции (типа Chen formula или упрощённые таблицы стартовых рук), постфлоп по силе руки + пот-оддсы.
5. **`table_state.py`** — общее состояние: банк (жёлтый текст "Общий банк X ББ"), ставки, кнопки действий (чек/колл/фолд/рейз с суммами), определение моего хода (появление кнопок внизу), жёлтая сумма на кнопке колла = есть ставка.
6. **Главный цикл** (`main.py`) — бесконечный: скриншот → определить состояние → если мой ход → распознать карты → оценить → решить → тапнуть → логировать. БЕЗ ИИ.

## Ключевые факты о столе (координаты, из отладки):
- Экран телефона: 1080x2400
- Кнопки действий (когда МОЙ ход):
  - «Чек»/«Колл»: центр (535, 2315)
  - «Фолд»: (185, 2315)
  - «Бет»/пресеты рейза: (880, 2315)
  - НЕ путать с автодействием «Чек/Фолд» с галочкой (x 45-520) — это НЕ кнопка!
- Признак моего хода: в зоне x 520-1080, y 0.86-0.99H появились кнопки (diff от базового кадра)
- Жёлтая сумма на кнопке колла (зона x 380-700) = оппонент поставил
- Мои карты: у аватара внизу (левая x ~40-150, правая x ~140-250, y 1730-1895), но лучше через cv2-контуры
- Доска: cv2-детекция белых карт в зоне y ~1050-1350
- Кнопка D: золотистый маркер (r>180, g>130, b<120, r>b+40) у аватара игрока (вверху = оппонент, внизу = я)
- Игроки: панели с аватаром/именем/стеком вокруг стола
